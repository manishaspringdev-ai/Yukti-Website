1. Executive Overview & Tech Stack

The Yukti Software Web Platform is an enterprise Single Page Application (SPA) designed to serve as both an IT Software Solutions Showcase and an Accredited Software Training Institute Portal based in Greater Noida. The architecture is engineered for ultra-fast load times, robust client-side lead capture, and zero-downtime content delivery through a hybrid database strategy.

Frontend Core React 18.3.1 Component-based UI, React.lazy & Suspense code-splitting.

3. Dynamic Data System (How Components Load Data)

The web platform implements a Fail-Safe Hybrid Data Architecture. Every component that presents dynamic information (courses, careers, campus photos, team members) queries Firebase Firestore first, while keeping a rich local dataset as a real-time fallback.

1
Component Mounts (e.g. AllCoursesPage, GalleryPage, CareersPage)
2
Invokes contentService.js getter function
3
Checks if Firebase Firestore is connected & returns live records
4
Smart Merge & Deduplication: Merges Firestore items with local catalog
5
Instant UI Render: Renders live data seamlessly without blank loading states

1. All Courses Page (AllCoursesPage.jsx)

Queries courses and custom_courses in Firestore. Automatically deduplicates by course slug/title against the 16+ master catalog, providing instant category filtering and real-time search.

2. Dynamic Course Detail (CourseDetailPage.jsx)

Dynamically binds route slug (e.g. course-python), fetching detailed curriculum modules, duration badges, FAQs, and custom image carousels from pagesDataFromDocs.js and courseImages.js.

3. Careers & Internships (CareersPage.jsx)

Fetches live openings from Firestore internship_roles. New roles added via Admin appear instantly with pre-populated application modals.

4. Photo & Video Gallery (GalleryPage.jsx)

Merges gallery_photos and gallery_videos from Firestore with 15+ local workshop assets, categorizing them into Collaborations, Labs, and Events.

4. Firebase Integration & Database Architecture

4.1 Safe Initialization (src/firebase.js)

Firebase is initialized defensively. If environment credentials are missing in .env, it gracefully logs a warning and permits the site to function in fallback mode without crashing. 

import { initializeApp, getApps, getApp } from 'firebase/app';
import { getFirestore } from 'firebase/firestore';

const firebaseConfig = {
  apiKey: import.meta.env.VITE_FIREBASE_API_KEY,
  authDomain: import.meta.env.VITE_FIREBASE_AUTH_DOMAIN,
  projectId: import.meta.env.VITE_FIREBASE_PROJECT_ID,
  storageBucket: import.meta.env.VITE_FIREBASE_STORAGE_BUCKET,
  messagingSenderId: import.meta.env.VITE_FIREBASE_MESSAGING_SENDER_ID,
  appId: import.meta.env.VITE_FIREBASE_APP_ID
};

export const app = getApps().length === 0 ? initializeApp(firebaseConfig) : getApp();
export const db = getFirestore(app);

5. Unified Multi-Channel Lead Engine (leadService.js)

When any student or enterprise client fills a form on the website, leadService.submitEnquiry() triggers a synchronized 4-tier dispatch pipeline:

Synchronized Lead Dispatch Steps:
  1. Database Record: Creates document in Firestore enquiries collection with serverTimestamp().
  2. Admin Email Notification: Dispatches real-time email alert to admissions team via EmailJS.
  3. User Auto-Reply: Sends branded confirmation auto-reply email to candidate's mailbox.
  4. WhatsApp Automated Message: Green-API pushes instant WhatsApp greeting with batch details to user's mobile number.
  5. Interactive Feedback: Triggers canvas-confetti and renders success confirmation modal.

7.3 Deployment Guidelines

Netlify / Vercel / Cloudflare

Pre-configured with public/_redirects containing: /* /index.html 200. Deploy repository directly with build command npm run build and publish directory dist.

Firebase Hosting / Apache cPanel

For Firebase, run firebase init hosting and set public directory to dist. For Apache, verify .htaccess includes standard rewrite rules to index.html.

Production Verification Checklist:
  • Run npm run build to confirm 0 compilation errors.
  • Ensure all environment variables in hosting provider match .env file.
  • Submit a test enquiry from Consultation Modal and verify Firestore record and email delivery.
